Configuration reference

Every key, flag, and environment variable, in one place — plus the two places where the README and the code disagree, flagged rather than silently reconciled.

15.1The file, section by section

Locations and precedence are Chapter 02. An absent table means "use the defaults"; a scalar or array in an overlay replaces wholesale; a table merges per key.

Top level

KeyTypeMeaning
modelstringRequired. The model id your endpoint serves.
base_urlstringAny OpenAI-compatible endpoint. Unset → api.openai.com, with a startup warning.
api_keystringOr OPENAI_API_KEY; a localhost base URL works keyless.
endpointchat|responses|autoDefault auto — derived from the model id (D025).
effortstringFree-style reasoning effort; omitted = nothing sent.

[models."<id>"]

Per-model provider overrides. Absent fields inherit the default provider; an unmapped model restores it, so a switch is reversible.

KeyMeaning
endpoint · base_url · api_keyRe-point the provider for this id only.

[hooks]

KeyValuesMeaning

[tools]

KeyDefaultMeaning

[theme] · [tui]

KeyDefaultMeaning
theme.namedefaultdefault · dark · light · gruvbox-dark · nord · solarized-dark · solarized-light · omarchy.
theme.<role>the preset17 roles (accent, dim, error, …) as a named ANSI colour or #rrggbb; explicit keys survive a preset switch.
tui.width68Transcript measure, 40–200. Out of range fails the load.
tui.viewfocusall or focus; an unknown token is a startup error.

[[team]] · [orchestrator] · [peers]

Covered in Chapter 11. Fields: name, role, model, tools, read_only, effort, base_url, api_key, file; plus orchestrator.guidelines and peers.<name>.

[workflow]

Covered in Chapter 13. Fields: max_attempts, timeout_secs, [[workflow.node]] (id, member|script, gate, title, timeout_secs), [[workflow.edge]] (from, to, condition).

Documented but absent: [workspace] digest_cas

README.md:99-103 documents a [workspace] digest_cas key for whole-file compare-and-swap. At this commit no such table or code exists: the digest machinery was removed together with the hash-anchor scheme (7c740fe). Setting it is harmless (an unknown table is ignored) and it does nothing. See Chapter 08 for why the design does not need it.

Unknown /… lines are sent to the model as prompt text, so a stray slash does not derail a turn.

15.5Validating a config

Three failures are loud on purpose: an out-of-range tui.width, an unknown tui.view token, and a duplicate or unknown [[team]] name. The rest are defaulted or warned.
