Teams & roles

A team is a roster of worker sessions the root can address by name. Roles are markdown files, not config blocks; the roster is a phonebook, not a hierarchy; and every message travels through an ownership edge the registry enforces.

11.1Turning it on

Two ways, and the second is the one that surprises people:

  • wcode --agents — register the root-only tools (spawn, message, peers, member, task).
  • A non-empty [team] auto-enables agents mode — no --agents needed (main.rs:799). In this repository, wcode alone starts the full team, because .wcode/team.toml exists.
KeyEffect
nameThe address. Unique; a duplicate fails the load loudly.
roleAppended to the worker's prompt as # Role.
toolsAllow-list. message is always kept — a worker with no way to report is a bug.
read_onlyRefuses the mutating tools and mutating bash/bg (ReadOnlyHooks).
model · effort · base_url · api_keyPer-member provider knobs; absent inherits the root's.
filePoint at a role file outside the scanned roots (cwd-relative or absolute); sibling keys override it.

11.2Roles are markdown files

Frontmatter supplies the member's fields; the body becomes its # Role. They are discovered from two roots, and folded under the TOML roster — so a TOML member of the same name wins wholesale.

PrecedenceSource
highestthe folded TOML [[team]]
./.wcode/agents/**/*.md (project)
lowest~/.config/wcode/agents/**/*.md (global — a team that travels)
The shadowing trap

A [[team]] entry of the same name as an .md role replaces it wholesale — not per field. A TOML member with only name and model silently drops the file's body, tools and read_only. If a role "stopped working", look for a TOML stub with the same name.

11.3Named project teams

A repository can ship several rosters and switch between them without rewriting config: one file per team under ./.wcode/teams/<name>.toml.

CommandEffect
wcode --team reconUse .wcode/teams/recon.toml as the overlay. Mutually exclusive with --config.
wcode --list-teamsPrint the discovered names and paths, exit.
/team(TUI) picker — the directory is the list.
/team roster · /team <name>Print the listing, or switch directly.

Selecting a named team replaces the project team.toml wholesale and suppresses the project ./.wcode/agents/ scan — "use this team instead" means exactly that.

11.4A worker's life

A spawned worker is a full session: its own model, its own tools, its own transcript. Two pieces of injected prose make it a worker rather than another root.

Report-back is a hook, not a habit

A worker is not asked to remember to report. ReportBack::after_run delivers its final message to the owner as a Wake — and when the run ended badly, it synthesizes a status line instead, so an orchestrator is never left waiting for a report that cannot come.

11.5Addressing, and who may talk to whom

Members are addressed by name; a bare name resolves through the phonebook, and an explicit agent:<id> reaches a session directly. Four delivery modes, and they are genuinely different:

ModeMeaningMid-run behaviour
wake (default)"Process this" — runs a turn even if the recipient is idle.Rides the follow-up channel.
notify"Know this" — appended to the conversation, no turn.Recorded now, or at the next boundary.
interrupt"Change course" — soft interrupt, does not cancel the run.Injected at the next turn boundary.
ask"Answer me" — a tool-free question, answered from context.Answered from the last turn-boundary snapshot.

The registry enforces scope

Addressing is not free-for-all. Registry::deliver resolves the pair through a permitted set built from ownership edges (a spawn creates one in each direction) plus explicit allow_pair grants. Anything else is NotPermitted — and a workflow's lateral edges are exactly such a grant.

Why a phonebook and not a tree

A worker may talk to its owner; two workers may talk if a workflow edge joined them. There is no manager chain to walk and no inherited capability — which is what makes a stale worker unable to chatter at a stranger, and a runaway spawn unable to recurse into a mesh.

11.6Supervising without waiting

The root can inspect a teammate while it works, without blocking its own turn:

Never sleep to wait for a worker

A worker's report arrives as a Wake — which can only be processed between the root's turns. So a polling loop, a sleep, or a blocking wait blocks the very message being awaited. SleepRefusalHooks refuses a sleep-leading command at the root for exactly this reason: the correct move is to end the turn.
