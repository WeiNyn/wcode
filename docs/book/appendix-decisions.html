A.3Glossary

TermMeans here
AgentThe kernel's stateful conversation object. Holds history, prompt, model, session.
RunOne invocation of run_loop: one or more turns until a stop reason.
TurnOne model call plus the tool calls it produced.
SessionA conversation and its JSONL file. With a team, a group directory.
Actor / handleThe task that owns an Agent, and the mailbox handle a client talks to.
BackendLocal or remote session handle — the seam clients code against.
HookOne of seven call sites where code can inspect, block, or rewrite a run.
RootThe orchestrator session: the only one with the task/spawn tools.
Worker / memberA spawned session with an owner; reports back automatically when its run ends.
PhonebookName → address resolution for members.
RegistryThe address book that enforces who may message whom.
Plan / task listThe root-owned DAG of Task nodes, journaled to plan.ndjson.
GateA node whose reject re-opens its dependencies instead of closing itself.
R′The rule that a work node cannot be completed unless a gate depends on it directly.
WorkflowA [workflow] plan template, instantiated at boot and driven headless when --task is given.
SkillA SKILL.md package: name + description in the prompt, body on demand.
Instruction fileAGENTS.md / CLAUDE.md-style conventions folded into the system prompt.
MeasureThe transcript's content width in columns (TUI).
SurfaceOne session's transcript inside the TUI; a team has one per member.

A.4Colophon

This book was written against the source at v0.13.0. Every code quote is a verbatim excerpt; elisions are marked // …, and a doc-comment summarised in place is labelled condensed in its caption. Where README.md and the code disagree, the book follows the code and says so — there are two such places at this commit, both flagged in Chapter 08 and Chapter 15.

Line numbers locate; the quoted text pins. A later reformat moves the number, not the claim.
