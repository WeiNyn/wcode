§Conventions in this book

Citations locate, quotes pin

Code is cited as crates/wcode-cli/src/tasks.rs:894 plus a quoted snippet. The number locates the line; the snippet still identifies it after a reformat moves the number. Anchors are relative to the workspace root.

Excerpts are excerpts

Snippets are trimmed to the point being made. An elision inside code is marked // …; a doc-comment summarised in place is marked condensed in the caption. Nothing is invented.

Decision numbers are load-bearing

D001–D034 are the repository's decision records, in docs/decisions/. This book cites them where a behaviour looks surprising but is deliberate. The appendix indexes all of them.

Two kinds of "why"

A blue note explains a mechanism. An amber note explains a decision — something that looks like a limitation and is not.

§What this book is built from

Source at v0.13.0 — everything merged since v0.12.0: README.md, AGENTS.md, docs/*.md (the plans), docs/decisions/*.md (the record), and the crates themselves — wcode-harness (the kernel), wcode-protocol (transport), wcode-tui (the full-screen client), wcode-cli (the composition root), editors/vscode (a second client). Where the README and the code disagree, the book follows the code and says so.

How to check a claim

Every mechanism in this book can be reproduced without an API key: wcode --dump-config, --dump-system-prompt, --help, or a run against a keyless local endpoint (--base-url http://localhost:11434/v1). Chapters name the check that proves them.
