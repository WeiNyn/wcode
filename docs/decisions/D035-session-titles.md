## The decision

A session's name is **content, not a filename**: a `SessionEntry::Title { id, title }`
appended to the JSONL transcript, last-write-wins, read by `Session::title()`. It is
produced by the model after `title_after_turns` assistant turns (default **2**,
`0` = off, range `0..=50`), and `/rename` / `--title` set it by hand.

The resume picker **replaces** rather than prefixes: a titled row is
`<title> · <age>`, an untitled row keeps the pre-W031 `<id> · <age> · <first user line>`.

## Why content and not a rename

Five parsers read the session filename and a rename would break every one: the
lexicographic-chronological listing, `age_millis` (parses the `{millis}_` prefix),
`GroupEntry::id`, the path handed back to `--resume`, and `session_search::session_id_of`.
The transcript entry has none of those dependents, inherits `Session::open`'s
torn-final-line tolerance, and is skipped by every released binary through
`#[serde(other)] Unknown` — verified live against the shipped `wcode 0.13.0`.

## Why the row replaces instead of leading

The request that opened W031 was *"semantic name > default id + first message"* — a
preference **over** the default, not a prefix. A four-part row
(`title · id · age · first line`) keeps every piece of noise the name was introduced
to replace, and it is exactly the width a picker truncates. Age stays as the
tiebreaker, because two sessions can share a name.

## Why the trigger blocks inline

Blocking at the turn boundary has the in-tree precedent of auto-compaction
(`compaction::compact_ctx` awaits inline and reports a miss non-fatally). The
alternatives were rejected on cost, not taste: a spawn-and-settle design needs a
settle wrapper around **eleven** `return finish(…)` exit sites, and a client-side
policy duplicates turn-counting outside the kernel.

The cost is stated rather than hidden: the title round-trip sits between
`AgentEvent::TurnEnd` and the tool dispatch, so that one turn's tools start one
request later. It is bounded by a **per-run** `title_tried` latch — set *before* the
call, so a failure consumes it — and it lands after the reply is already on screen.
A failed title is therefore **silent**: no entry, no event, no error. Unlike
`CompactionSkipped`, a miss here is cosmetic, at most once per run, and offers the
user nothing to act on.

## Consequences

- **The title call drops reasoning effort** (`title_llm.effort = None`, same model).
  A naming request should be the least-deliberative call in the system; without this
  a reasoning model can emit thinking-only and the session silently never gets a
  name. Thinking-text fallback was rejected — a thinking block's first line is
  planning prose, so it would store worse names *and* hide the miss.
- **A compacted session no longer labels itself**
  `Summary of the earlier conversation (auto-generated by compaction):`. That was a
  defect found while briefing: `messages()` prepends the summary as a `User` message
  and the picker took the first `User`, so the longest sessions were the ones you
  could not tell apart. `COMPACTION_SUMMARY_PREFIX` is now one const in `message.rs`
  with two readers.
- **`/sessions` rows stay pasteable.** The listing prints `<file> · <title>` — the
  filename leads because `resolve_session_path` documents that listing output can be
  pasted back into `/resume`. Surfacing the title there is not a licence to replace
  the actionable token.
- **`/rename` works over a socket**, unlike `/resume`: it is a `Request` the server
  applies, whereas `/resume` is a client-side directory listing the server does not
  own.
- **A titled session is not filterable by id** in the TUI picker, since the label
  replaced it. Recorded as a follow-up, not fixed here.

## Rejected

- A `meta.json` sidecar — a second reader, a second path convention for group
  directories, and no torn-write story.
- Re-titling every N turns — churn, semantic drift, and it renames a session the
  user has learned to find.
- A `TitleSkipped` event — see the silence argument above.
- Falling back to thinking content, or to the whole `ctx` as titler input (unbounded
  cost, and the tail describes the latest work rather than the session's purpose).
