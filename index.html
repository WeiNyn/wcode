wcode

A minimal, pi-like coding agent for the terminal — small, token-lean, and team-first.

A few-hundred-line kernel over any OpenAI-compatible endpoint, with a thin CLI and a full-screen TUI.

Install GitHub

Three ideas, taken seriously

  • 1Simple

    One small kernel (wcode-harness) — event loop, tool dispatch, hooks, JSONL sessions — and a thin CLI. No MCP, no subagent framework, no permission prompts, no behavior config: policy lives in code, via Hooks.

  • 2Token-minimal, built in

    Content-addressed read/edit — old code is never re-typed. bash spills large output to a file and returns a bounded preview. Auto-compaction keeps the window lean, and an rtk hook can proxy shell output. Fewer tokens, less context drift.

  • 3Teams & workflows first

    Spawn named members and message them by name; run a real task DAG with gates, dependency edges, and rework caps; declare the whole team and workflow in [team] / [workflow]. Each member is its own surface in the TUI. 

$ wcode --agents --config .wcode/team.toml
# your team · explorer (read-only) · builder · reviewer

❯ implement the retry policy, then have it reviewed
⚙ message(explorer) → "map the retry seam"         ✓ done
⚙ task(create) #1 explore → #2 implement → #3 verify
⚙ message(builder)  → "#2 implement"               ● running
⚙ message(reviewer) → "#3 review the diff"         ○ queued

read · grep/find · bash · edit — content-addressed, token-lean

Install

  1. Homebrew

    brew tap WeiNyn/wcode https://github.com/WeiNyn/wcode
brew install wcode

  2. crates.io

    cargo install wcode-cli

  3. Prebuilt binaries

    Linux (x86_64, aarch64) and macOS (Intel, Apple Silicon) tarballs are attached to each release.

Quickstart

~/.config/wcode/config.toml:

model = "gpt-4.1"                          # required
base_url = "https://api.openai.com/v1"     # optional; any OpenAI-compatible endpoint
api_key = "sk-..."                         # optional
wcode -p "explain this repo"   # one-shot
wcode                          # start the TUI
wcode --agents                 # start with a team + workflow
