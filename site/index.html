wcode

A minimal, pi-like coding agent for the terminal. It streams an LLM conversation and gives it content-addressed tools — read (anchors per line), grep/find, bash, edit/edits/replace, write, and ast-grep search/rewrite — and stays out of the way.

Built on a small kernel (wcode-harness) that speaks to any OpenAI-compatible chat-completions endpoint.

Install GitHub 

$ wcode -p "explain this repo"
wcode — model: gpt-4.1

This is wcode: a small terminal coding agent. The kernel is a few
hundred lines — event loop, tool dispatch, hooks, JSONL sessions — and the
CLI is a thin client over any OpenAI-compatible endpoint.

$ wcode --resume
resuming latest session…

What it is

  • Content-addressed tools

    read emits a 5-char ANCHOR│line; edit targets anchors, so edits above never shift the target.

  • Any endpoint

    Speaks to any OpenAI-compatible chat-completions endpoint — OpenAI, Ollama, a gateway.

  • Small kernel

    wcode-harness is a few hundred lines: event loop, tool dispatch, hooks, JSONL sessions.

  • Full-screen TUI

    A ratatui client of the same AgentEvent stream, with a line REPL fallback for pipes and CI.

  • Parallel tools

    Independent read-only calls run concurrently; mutating tools and bash are barriers.

  • No approval flows

    Absent by design: MCP, subagents, permission prompts. Policy lives in code, via Hooks.

Install

  1. Homebrew

    brew tap WeiNyn/wcode https://github.com/WeiNyn/wcode
brew install wcode

  2. crates.io

    cargo install wcode-cli

  3. Prebuilt binaries

    Linux (x86_64, aarch64) and macOS (Intel, Apple Silicon) tarballs are attached to each release.

Quickstart

~/.config/wcode/config.toml:

model = "gpt-4.1"                          # required
base_url = "https://api.openai.com/v1"     # optional; any OpenAI-compatible endpoint
api_key = "sk-..."                         # optional
wcode -p "explain this repo"   # one-shot
wcode                          # start the TUI
